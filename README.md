# VEKTOR Microsite

VEKTOR ist ein fiktives KI-Beratungsunternehmen, das im Rahmen eines **Universitätsprojekts im Bachelorstudium Medieninformatik** konzipiert wurde. Die selbst entwickelte Microsite dient der Präsentation dieses Unternehmens und basiert auf React.js und Tailwind CSS. Der Fokus liegt auf einer dynamischen, modernen und multimedial aufbereiteten Website.

## Technologien & Architektur

* **React + Vite:** Komponentenbasierte Struktur und Entwicklung der Website
* **Props:** Übergabe von Inhalten und Eigenschaften an wiederverwendbare Komponenten
* **`.map()`:** Dynamische Darstellung von Navigation, Services, Timeline-Elementen und Medien aus Daten-Arrays
* **Tailwind CSS:** Responsive Layouts, Styling und Breakpoint-Management
* **`index.css`:** Zentrale CSS-Datei und Einbindung von Tailwind
* **Motion:** Animationen und Scroll-basierte Interaktionen mit `motion/react` (https://motion.dev)
* **React Bits:** Verwendung ausgewählter interaktiver UI- und Animationselemente (https://reactbits.dev/)
* **Wiederverwendbare Komponenten:** z. B. Service Cards, Timeline Items und Media Items
